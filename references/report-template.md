# 黄金综合研判报告模板

> 用法：先运行 `python gold_monitor.py --brief` 获取带时间戳的实时数据快照，再按下列结构补全宏观与研判。
> 原则：所有数字必须来自本次抓取并标注时间；宏观数据必须为最新，取不到就写“未获取/待更新”，不得沿用旧值。

## 一、数据快照（实时）
- 抓取时间：YYYY-MM-DD HH:MM（本地）
- 国际金价：$____/oz（源更新时间：____）
- USDCNY：____（源更新时间：____）
- 积存金参考：____ 元/克（= 金价 × USDCNY ÷ 31.1035）
- 10Y美债收益率：____%（数据日期：____；Treasury.gov 主 / FRED 备）
- 金债比：____（= 金价 ÷ (10Y% × 1000)）

## 二、金债比六档位置（随 10Y 动态反推）
| 档位 | 含义 | 国际金价 | 积存金 |
|---|---|---|---|
| 0.6 | 强支撑 / 低估 | $____ | ____ 元/克 |
| 0.7 | 支撑 | $____ | ____ 元/克 |
| 0.8 | 近端支撑 | $____ | ____ 元/克 |
| 1.0 | 阻力 | $____ | ____ 元/克 |
| 1.1 | 近端阻力 | $____ | ____ 元/克 |
| 1.23 | 强阻力 / 高估 | $____ | ____ 元/克 |

- 当前位置：____，位于 ____ 档与 ____ 档之间，距最近档位 ____%
- 档位强化/削弱：____（例：宏观偏空→0.8/0.7 支撑更受考验；央行购金托底→0.7 附近支撑增强）

## 三、宏观面（截至 YYYY-MM-DD，必须最新）
- 美联储：最近议息结果、沃什讲话、下次会议时间与加息/降息概率
- 非农：最新一期新增就业、失业率、薪资增速；对金价影响
- 通胀与实际利率：最新 CPI/PPI/核心PCE、10Y 实际利率
- 宏观结论：偏多 / 偏空 / 中性；核心驱动 ____

## 四、情绪与资金（三项全自动，见 `--brief` 输出）
- SPDR 持仓：____ 吨（日变动 ____｜5日变动 ____；截至 ____，来源 自动/缓存）
- VIX：____（截至 ____ 收盘；注意美股时段外只能是上一交易日收盘）
- 内外盘溢价：____%（上金所 Au99.99 vs 国际金折算；行情超 24 小时标过期、不参与判定）
- 情绪结论：偏冷 / 偏暖 / 中性 / 分歧 / 数据不足 → 对应短语「____」
- 可选人工补充（不参与打分）：CFTC 净多、央行购金、地缘事件

## 五、技术面（MA5/MA60 定趋势，布林带定位置；新浪沪金主力连续 元/克）
- 数据日期：____（日线收盘确认 / 盘中待确认）；收盘：____ 元/克
- MA5：____｜MA60：____（差 ____%）→ 趋势：多头 / 空头
- 布林带（M=20，K=2）：中轨 ____｜上轨 UB ____｜下轨 LB ____
- 价格位置：上轨外（超买）/ 中轨上方（偏强）/ 中轨下方（偏弱）/ 下轨外（超卖）
- 最近交叉：金叉 / 死叉（日期 ____）；交叉差 ____%
- 组合判断：____（多头回踩低吸 / 多头超买不追 / 空头反弹高抛 / 空头超卖不抄底 / 观望）
- 盘中参考：积存金现价 ____ 元/克 → 盘中位置 ____（信号以收盘确认为准）
- 关键支撑：____（对应金债比 ____ 档）
- 关键阻力：____（对应金债比 ____ 档）
- 形态/量能/指标：____
- 短线关键位：____

## 六、综合研判
- 金债比定位：____（六档中的位置）
- 宏观偏度：____；情绪用语：____（须与卡片「操作」行括号内一致）；技术校准：____
- 支撑区间：____–____ 元/克（$____–$____）
- 阻力区间：____–____ 元/克（$____–$____）
- 判断：偏多 / 偏空 / 震荡；操作建议：分批建仓 / 观望 / 分批止盈
- 风险提示：____（议息、非农、CPI、地缘等）

## 七、数据时效声明
- 价格/汇率/收益率抓取于 YYYY-MM-DD HH:MM
- 宏观数据截至 YYYY-MM-DD
- 宏观数据超过 1 天未更新：必须标注“已过期 N 天”，不得当作最新使用
- 未获取的数据：____（如实标注，不得省略）
